# HTML Advanced

## Description

This project is an introduction to building webpages using HTML5. It focuses on understanding the basic structure of an HTML document, including the doctype declaration, root HTML element, language attributes, and text direction.

The goal of this project is to learn how browsers interpret HTML structure and how to create a valid foundation for future webpages.

## Learning Objectives

By completing this project, I learned:

* How to create an HTML5 document structure.
* The purpose of the `DOCTYPE` declaration.
* How to use the `<html>` root element.
* How to define the page language using the `lang` attribute.
* How to set text direction using the `dir` attribute.
* The importance of writing clean and organized HTML code.
